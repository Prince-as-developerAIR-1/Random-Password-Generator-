# 🚀 SPACE PASS Random-Password-Generator-

> Generate strong, secure passwords from outer space!
> Space Pass is  beautiful space-themed random password generator that creates strong, secure passwords with customizable options and a cool galaxy animation.

---

## Live demo

Just open `index.html` in your browser - no needed to setup! OR open -
```
https://prince-as-developerair-1.github.io/Random-Password-Generator-/
```

---

## Features

- Adjustable passord length (4 to 30 characters)
- Custom character types - ABC, abc, 123, @#$
- Real-time strength checker (Weak / Medium / Strong)
- One-click copy to clipboard
- Animated stars background with purple galaxy theme
- Fully responsive - works on phone and desktop

## How to use

1. Select your desired password length
2. Choose what to include (uppercase, lowecase, numbers, symbols)
3. Click GENERATE PASSWORD
4. Copy and use it!
